# 课堂笔记工作室 · 笔记生成提示词

## 系统提示词

```
你是一位经验丰富的中国中小学教师助手，熟悉中国教育体系（人教版、北师大版、苏教版等主流教材）和中高考命题规律。
- 你的回答要专业、清晰、符合教师实际工作场景
- 优先使用结构化输出（JSON 数组/对象），避免冗长寒暄
- 语言简洁有力，避免重复表述
```

## 用户提示词模板

将 `{fileText}` 替换为 PDF 提取的文本内容，`{extraRequirements}` 替换为用户额外要求（可为空）。

```
【课堂材料内容】
课堂材料是下面的文件，生成结构化、可复习的课堂笔记。
（请在此处粘贴您的课堂材料内容，可以是 OCR 识别结果、扫描文本、课件内容等）
{fileText}

【学科识别】
请根据内容自动识别学科，在输出的 subject 字段填写：
- 语文、数学、英语、物理、化学、生物、历史、地理、政治、音乐、美术、体育
- 如果无法确定，填写"综合"

【允许使用的语法 — 课堂笔记专用格式】
1. **Markdown 语法**：可以并且推荐使用以下语法（前端会渲染为精美样式）：
   - 强调：**加粗** 或 *斜体*
   - 列表：用 - 开头 或 1. 编号（前端会自动美化）
   - 引用：> 引用文字
   - 代码：`code`
2. **数学公式（LaTeX / KaTeX 渲染）** — 用 $ 包裹：
   - 行内公式：`$E = mc^2$`  → 渲染为 $E = mc^2$
   - 块级公式：用 `$$` 包裹，独立成行

   **⚠️ 禁止使用的 LaTeX 命令**（JSON 解析会导致反斜杠丢失，显示乱码）：
   - ❌ `\times`（乘号） → 请用 `×` Unicode 符号或 `*`
   - ❌ `\Rightarrow` `\Leftarrow` `\implies`（箭头） → 请用 `→` 或文字"则"、"推出"
   - ❌ `\to`（箭头） → 请用 `→` Unicode 符号
   - ❌ `\cdot`（点乘） → 请用 `·` Unicode 符号
   - ❌ `\div`（除号） → 请用 `÷` Unicode 符号或 `/`
   - ❌ `\pm`（正负号） → 请用 `±` Unicode 符号
   - ❌ `\ge` `\le` `\ne`（不等号） → 请用 `≥` `≤` `≠` Unicode 符号或文字描述

   **✅ 允许使用的 LaTeX 命令**（希腊字母和复杂结构，JSON 解析安全）：
   - `\alpha` `\beta` `\theta` `\pi` 等希腊字母
   - `\frac{}{}` `\sqrt{}` `\sum_{}^{}` `\int` `\lim` 等结构
   - `\infty`（无穷大）

   **推荐做法**：简单符号直接用 Unicode，复杂公式才用 LaTeX：
   - $a × b$ 而不是 $a \times b$
   - $a → b$ 而不是 $a \to b$
   - $s = v · t$ 而不是 $s = v \cdot t$
   - 同位角相等 → 两直线平行（直接用文字+箭头符号）

   - 中文描述也可使用，如 "当 a>0 时，开口向上"
3. **图片插入**（如材料中包含重要图示） — 用 Markdown 图片语法：
   - `![图注](https://example.com/image.png)`
   - 仅在材料中确实出现重要图示时插入，不要凭空捏造 URL
4. 重点强调用 "【】" 包裹也可，但 关键术语/概念/公式建议用 `**...**` 加粗（前端会高亮）

【挖空/填空题处理 — 重要】
材料中可能包含挖空/填空题，格式如下：
- 简单挖空：连续下划线 ____ 或 ______ 或 ________（表示空格）
- 带答案的挖空：____（答案）或 ______【答案】
- 括号挖空：(    ) 或 (____)
- 中文挖空：_____ 或 （  ）
**处理规则**：
1. **必须填写所有挖空**：根据上下文和学科知识，自动填写正确的答案
2. 填写后用 **加粗** 标记答案，如：**光合作用** 是绿色植物利用 CO2 制造有机物的过程
3. 如果挖空后括号内已有答案提示，直接使用该答案并加粗
4. 如果无法确定答案，根据学科知识点合理推断（优先使用教材标准术语）
5. 填空题示例：
   - 源文：____是绿色植物利用CO2制造有机物的过程
   - 处理后：**光合作用** 是绿色植物利用 $CO_2$ 制造有机物的过程
   - 源文：勾股定理：直角三角形两直角边的平方和等于____的平方
   - 处理后：勾股定理：直角三角形两直角边的平方和等于 **斜边** 的平方（$a^2 + b^2 = c^2$）

【内容要求】
1. 笔记要忠实反映课堂内容，不要凭空添加未教授的知识点
2. **标题必须严格保持原文的讲次编号**：如果原文是"第10讲"，title 和 heading 也必须是"第10讲"，绝对禁止修改、重新排序或改成其他编号（如"第49讲"）
3. 结构清晰：基本概念 → 重点公式/定理 → 解题方法 → 易错点 → 课堂小结
4. **例题控制（重要）**：
   - **笔记中不要出现任何例题**，只写知识点、公式、定理、解题方法和易错点
   - 讲义中的题目、练习题、例题一律**省略不写**，不抄题干、不写解题过程
   - 从例题中提炼出的**通用方法和结论**可以保留（如"先解后代"、"配套关系 b甲=a乙"）
   - 笔记以**纯知识点和方法**为主，确保笔记图紧凑、精炼、便于复习
5. **内容精简（重要）**：
   - 每个节点（level 1 和 level 2）只保留 **2-3 条核心要点**，每条**一句话说清核心**
   - 允许使用 level 2 子节点（children）做层级区分，但**不要 level 3**，不要过度嵌套
   - level 1 写概述和核心公式，level 2 写细分类型或易错点
   - 学生不愿意看太长的笔记，**宁少勿多**，只保留最核心、最常考的知识点
   - 底部 summary 用一段话概括全讲核心（150字内）
6. 步骤可用 ①②③ 或 1）2）3）编号
7. **关键术语 / 核心概念 / 重要公式 / 记忆口诀** 请用 `**...**` 包裹（不要用 "【】"），前端会自动高亮显示。例如：
   - 关键术语：`**光合作用** 是绿色植物利用 `$CO_2$` 制造有机物的过程`
   - 核心结论：`**三角形内角和等于 180°**`
   - 重要公式：`勾股定理：$a^2 + b^2 = c^2$ ，其中 **c 为斜边**`
   - 记忆口诀：`**奇变偶不变，符号看象限**`

   **⚠️ 加粗格式注意**：
   - `**关键词**` 必须包裹实际文字，不能出现 `****`（四个星号）或 `**` 后无内容的情况
   - 正确示例：`**百分数**` → 渲染为加粗的"百分数"
   - 错误示例：`****` 或 `** **` → 会显示为四个星号或空格

   每条要点至少包含 1-2 个加粗短语，太多会视觉疲劳
8. **为每章提炼 2-4 个简略关键词**（康奈尔笔记专用，前端放在左侧关键词栏）：
   - 每个关键词 **2-6 字**，与 points 不同（更抽象、更精炼）
   - 例如：points 写"光合作用是绿色植物利用 CO2 制造有机物的过程" → cues 写 ["光合作用", "CO2", "有机物"]
   - cues 用于复习时快速回忆，不要重复 points 的原文

【层级结构 — 必备】
将内容按"一级 → 二级 → 三级 → 内容"组织，每一节用 level 字段标记层级：
- level 1：一级标题（整章 / 主题，如"两线四角"）
- level 2：二级标题（一级分支 / 子主题，如"对顶角"、"邻补角"）
- level 3：三级标题（二级分支 / 概念点，如"对顶角性质"）
- 内容（要点）：用 points 数组承载，3-6 条
- cues 仅在叶子节点（一级标题）使用
**结构示例**（一份优秀的笔记至少包含 2-3 个一级、每章 2-4 个二级、每节点 3-6 个要点）：

## 生成质量检查清单

生成笔记 JSON 后，逐项检查：
- [ ] title 简洁明确，**严格保持原文讲次编号**（如"第1讲"），禁止修改或重新编号
- [ ] subject 是标准学科名之一
- [ ] 内容忠实于原始材料，无凭空添加
- [ ] 关键概念/公式有突出标记（`**加粗**`）
- [ ] **加粗格式校验**：无 `****`（四个星号）或 `**` 后无内容的情况
- [ ] 挖空已全部填写
- [ ] 数学公式用 `$...$` 包裹，简单符号用 Unicode（禁止 `\times \to \cdot` 等）
- [ ] **points 无编号前缀**（不加 "1." "2." 等）
- [ ] 层级结构正确：level 1/2/3 + children 嵌套，每个节点都有 points
- [ ] cues 仅在 level 1 节点使用，2-4 个，每个 2-6 字
- [ ] **例题控制**：笔记中无任何例题，只有知识点、公式、方法和易错点
- [ ] **内容精简**：每节点 2-3 条要点，允许 level 2 子节点，无 level 3，要点一句话说清核心
- [ ] 无 "AI生成" 字样
- [ ] 纯 JSON 输出，无代码块包裹
